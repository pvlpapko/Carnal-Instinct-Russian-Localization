2. Разрешённое использование
Вы можете бесплатно установить и использовать русификацию для личного использования с имеющейся у вас копией игры. Разрешается создавать резервные копии русификации и передавать её другим пользователям бесплатно, если сохранены это соглашение, сведения об авторе Don't Look и состав исходной сборки.

Вы можете изменять материалы, созданные автором русификации, для личного использования. Эти разрешения распространяются только на материалы, права на которые принадлежат автору русификации.

4. Совместимость и установка
Выберите комплект, соответствующий вашей версии игры. Для NoSteam 0.7.9.16232 предусмотрен отдельный комплект. Steam и вариант NoSteam 0.7.9.16313 / 16315+ используют актуальный комплект из стабильной папки Steam_current внутри этой сборки установщика. При последующих обновлениях установщика эта папка обновляется без создания нового versioned Steam-пути. Файлы NoSteam 0.7.9.16232 с Steam_current не смешиваются. Установщик не загружает обновления из сети.
Перед установкой или удалением закройте игру. Установщик проверяет файлы русификации, удаляет предыдущий комплект и устанавливает новый без создания резервных копий. Старые резервные копии этого русификатора удаляются. При удалении русификации предыдущие комплекты не восстанавливаются.
